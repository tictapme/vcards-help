# Activar mi usuario app

En este artículo, te guiaremos paso a paso para **activar tu cuenta y acceder a tu vcard**. Este proceso incluye la activación inicial desde un correo electrónico, la aceptación de términos y condiciones, la creación de un patrón de desbloqueo, y finalmente, el acceso y configuración de tu cuenta. Sigue cada uno de los pasos descritos a continuación con sus respectivas imágenes para completar la activación de tu usuario de manera sencilla y rápida.
