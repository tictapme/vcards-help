# ¿Qué es una marca?

Las marcas son una forma eficaz de organizar y gestionar vcards en grupos específicos. Por ejemplo, puedes crear diferentes marcas para cada una de las siguientes categorías dentro de una empresa: <br> 
- **Subdivisiones:** como sucursales o divisiones geográficas. <br> <br>
- **Submarcas:** identidades comerciales o marcas secundarias dentro de la empresa. <br> <br>
- **Departamentos:** áreas funcionales como ventas, marketing, recursos humanos, etc. <br> 

☝ Estas marcas permiten agrupar vcards que comparten un mismo estilo o tipo de información relevante, facilitando así la organización y el acceso rápido a contactos específicos dentro de la estructura organizativa de la empresa. Sin embargo, si eres una empresa más pequeña, también puedes optar por tener una sola marca para gestionar todos tus contactos de manera centralizada y efectiva.

Ahora que tienes conocimiento sobre qué son las marcas y cómo se utilizan, puedes proceder a crear una nueva marca.
